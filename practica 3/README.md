# practica 3 de mineria de datos

## objetivo

visualizar los datos limpios de anilist mediante diferentes tipos de graficas.

el programa crea las siguientes graficas:

- pastel de formatos
- histogramas de variables numericas
- diagramas de caja de variables numericas
- dispersion de calificacion y popularidad
- barras de los diez generos mas comunes
- linea de cantidad de anime por año

los histogramas y diagramas de caja se generan automaticamente mediante ciclos.

para instalar las dependencias y ejecutar el programa:

```bash
pip install pandas matplotlib
python visualizacion_datos.py
```

las imagenes se guardan en la carpeta `resultados`.
